# John-Willeit-Institute

A Python-based project with web components for the John Willeit Institute.

## Overview

This repository contains a web application built with Python backend and HTML/CSS frontend. The project is designed to serve the needs of the John Willeit Institute.

## Technology Stack

- **Python**: 67.4% - Core backend logic
- **HTML**: 30.6% - Web interface markup
- **CSS**: 1.8% - Styling
- **Shell**: 0.2% - Utility scripts

## Getting Started

### Prerequisites

- Python 3.x installed
- Git

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Djakba-Faustin/John-Willeit-Institute.git
   cd John-Willeit-Institute
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Running the Application

To start the application:
```bash
python main.py
```

- Python modules and backend logic
- HTML templates for web interface
